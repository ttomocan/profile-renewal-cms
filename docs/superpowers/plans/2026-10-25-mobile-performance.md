# スマホ優先の速度調査・改善計画

**目的:** profile-renewal-cms のみを調査し、表示と既存機能を保つ低リスク変更を計測・検証して公開する。

**構成:** main `658739d919ab4d116a5f7edaff47b656c3419c81` の production build を保存する。秘密値を使わない固定CMS応答をビルド・起動時だけ差し替え、製品のCMS実装は変更しない。表示専用カードのサーバー描画を候補とし、操作を持つ CardSlider はクライアントに残す。

**技術:** Node 24 / Next.js 16.4.1 / React 19 / Chromium / Playwright。

**制約:** デザイン、掲載内容、URL、SEO、フォーム、CMS、依存バージョンを維持する。他リポジトリ、認証、DB、秘密値、本番コンテンツ、compression 残件は対象外。公開サイトの proxy 403 は迂回しない。追加承認待ちは不要という依頼に従い、このセッションで実装・検証・リリースを進める。

## 確認重点

- 空のCMS一覧と画像なしカードでもSSRのリンク・操作ラベルが維持される。
- SPの前後移動・キーボード・非表示スライドのフォーカス制御を保つ。
- 768pxの境界、PCグリッド、縮小モーション、JSなし表示を保つ。
- 往復遷移後もカードが操作でき、表示テキスト・メタデータが一致する。
- 計測は同一内容・端末設定・CPU・通信・キャッシュ条件で反復し、本番指標とは区別する。
