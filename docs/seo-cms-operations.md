# SEO・microCMS運用メモ

## 実績APIに追加する推奨フィールド

すべて任意項目とし、NDAなどで公開できない情報は空欄にします。空欄のセクションは画面に出力されません。

| APIフィールド | 種別 | 用途 |
| --- | --- | --- |
| `seoTitle` | テキスト | 検索結果・OGP用タイトル。案件名のH1とは分離する |
| `seoDescription` | テキストエリア | サイト種別、規模・課題、本人の担当範囲、使用技術、改善内容を事実の範囲で記載する |
| `coverAlt` | テキスト | カバー画像が本文で意味を持つ場合だけ入力する |
| `challenge` | テキストエリア | 課題・背景 |
| `constraints` | テキストエリア | 公開可能な制約条件 |
| `responsibility` | テキストエリア | 本人が担当した範囲。チーム全体の成果と混同しない |
| `decisions` | テキストエリア | 実装時の判断と理由 |
| `results` | テキストエリア | 確認できる改善結果・成果。推測の数値は入力しない |
| `outOfScope` | テキストエリア | 担当外の範囲 |

現在はSEO専用フィールドがないため、既存CMSデータだけを根拠にしたフォールバックをコード側で使用しています。フィールド追加後は、入力値がフォールバックより優先されます。

## ブログAPIに追加する推奨フィールド

| APIフィールド | 種別 | 用途 |
| --- | --- | --- |
| `seoTitle` | テキスト | 検索結果・OGP用タイトル。記事H1とは分離する |
| `seoDescription` | テキストエリア | 検索結果・OGP・BlogPostingで共通利用する説明文 |
| `thumbnailAlt` | テキスト | アイキャッチ自体に意味がある場合の代替テキスト |

現在の9記事には、監査で指定されたSEO titleをコード側のフォールバックとして設定しています。microCMSに同じ値を移行すれば、以後は編集画面から更新できます。

## カテゴリ運用

2026年8月4日時点では「活動記録」8件、「お知らせ」1件です。3件未満の「お知らせ」は `noindex, follow` とし、sitemapから除外しています。カテゴリURLは変更していません。

今後「Web開発」「個人開発」「ブログ運営」「キャリア・働き方」「育児・暮らし」「お知らせ」へ整理する場合も、原則3記事以上になるカテゴリだけをindex対象にしてください。既存カテゴリIDを変更する場合は、旧URLから新URLへの恒久リダイレクトを先に設計します。

## 画像altの運用

- 一覧カードは直後のタイトルと読み上げが重複するため、画像altを空にしています。
- 記事本文内でaltが未入力、`Image`、`画像`、ファイル名だけの場合は空altへ正規化します。
- 内容を特定できない画像へ推測の説明を入力しないでください。
- 意味のある記事アイキャッチは `thumbnailAlt`、実績画像は `coverAlt` を利用してください。
