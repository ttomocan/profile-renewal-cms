# アクセシビリティ改善レビュー（2026-11-16）

対象: tomocan.site。WCAG 2.2 を参考にした実装・主要画面の改善であり、全ページの適合認証ではありません。

## 確認して修正した点

1. お問い合わせ入力のフォーカスを指定どおり2px・隙間なしに変更。
2. 検索入力とカテゴリー選択も2pxの濃いフォーカス枠へ。
3. 検索・カテゴリーの薄い境界を識別しやすい色へ変更。
4. 検索入力・検索ボタンの高さを44px以上にし、320px幅の入力縮小に対応。
5. 検索フォーカス時の位置の跳ねを除去。
6. フォームエラー文字を明るい赤から濃い赤へ変更（白背景で約7.54:1）。
7. フォームエラー時に入力済み内容が消える不具合を修正。テキストとラジオ選択を維持。
8. ヘッダー・フッターの現在位置にaria-currentを追加。
9. ページ上部ボタンが消える前に本文へフォーカスを移し、隠れたボタンに残さない。
10. 動きを減らす設定時にリサイズで波が動き始める不具合を修正。
11. OSの動きを減らす設定変更へ追従。
12. 波の自動再生を4.5秒以内で停止。リサイズ・再レンダーによる延長を防止。

## 検証

- 変更前の回帰テスト失敗と変更後成功を確認。新規・関連テスト11件成功。
- 全体テストは129/130成功時点で既存のトップ文言期待値1件のみ失敗。最新mainを別worktreeで調べ、同じ失敗を再現。今回の変更対象外。
- ESLint、TypeScript、ローカルCMS fixtureによるNext.js build成功。
- Chrome実ブラウザ: お問い合わせのエラー、入力保持、ラジオ保持、エラー欄へのfocus、2px/offset 0を確認。
- Chrome実ブラウザ: 320px幅でお問い合わせ・検索の横はみ出しなし、検索高さ44pxと2px枠を確認。
- ページ上部でmainへfocus移動、モバイルメニュー開閉/Escapeを確認。
- 本番フォームへ送信していない。ローカルでは必須不足の検証だけを実行し、外部送信条件へ到達していない。
